# Бот-редактор для Telegram-каналов (на GigaChat)

Каждое утро бот сам берёт тему из `plan.json`, ищет в интернете материалы, пишет черновик через GigaChat и присылает вам в личку. Вы нажимаете кнопку, и пост уходит в канал.

## Как это выглядит

Приходит сообщение с черновиком и кнопки:

- ✅ Опубликовать: пост сразу уходит в канал
- ✏️ Править: вы присылаете готовый текст, бот показывает его снова на подтверждение
- 🔁 Переписать: вы пишете, что поменять («короче, добавь пример»), бот делает новую версию
- ❌ Отклонить

Под черновиком бот отдельно пишет, что стоит проверить, и ссылки на найденные источники.

Команды: `/draft` (по одному черновику на каждый канал), `/draft prompt_tochka` (для одного), `/draft prompt_tochka своя тема` (на вашу тему), `/status`.

## Установка

### 1. Telegram
1. В @BotFather: `/newbot`, получите токен.
2. Добавьте бота **админом** в оба канала с правом публикации.
3. Напишите @userinfobot, он ответит вашим числовым ID (это `OWNER_ID`).
4. Откройте диалог со своим ботом и нажмите Start, иначе он не сможет вам писать.

### 2. GigaChat
1. Зайдите на https://developers.sber.ru, войдите через Сбер ID.
2. В личном кабинете создайте проект GigaChat API.
3. В разделе «Авторизационные данные» нажмите «Сгенерировать Authorization Key». **Ключ показывается один раз**, сразу сохраните его в `.env` как `GIGACHAT_AUTH_KEY`.
4. Посмотрите баланс токенов в кабинете. По официальной странице тарифов физлицам положен бесплатный пакет (365 млн токенов на 12 месяцев), но там же сказано, что с сентября 2026 года условия для новых клиентов могут отличаться. Реальную сумму покажет кабинет.

Для двух постов в день нужно очень мало: примерно 7 тысяч токенов на пост (это оценка), то есть около 14 тысяч в день.

### 3. Сертификат Минцифры (без него будет ошибка SSL)
GigaChat использует российский корневой сертификат. Скачайте его:

```
curl -k -o russian_ca.crt https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
```

и укажите путь в `.env`: `GIGACHAT_CA_BUNDLE=/полный/путь/russian_ca.crt`.

Если всё равно ошибка проверки, на крайний случай можно поставить `GIGACHAT_VERIFY_SSL=0` (и убрать `GIGACHAT_CA_BUNDLE`). Это небезопасно: ключ идёт по каналу без проверки сервера. Лучше установить сертификаты по инструкции https://developers.sber.ru/docs/ru/gigachat/certificates.

### 4. Запуск
```
cp .env.example .env     # и заполните
pip install -r requirements.txt
python bot.py
```
Затем отправьте боту `/draft` и посмотрите, что придёт.

## Настройка

- `config.json`: названия каналов, `chat_id` (@имя канала), время черновиков (`draft_times`), часовой пояс, `search_hint` (о чём искать, когда тему выбирает сам бот).
- `plan.json`: очередь тем. Когда темы кончатся, бот сам предложит тему, учитывая последние посты.
- `style.md`: **самый важный файл.** Вставьте в него 3–5 ваших настоящих постов и дополните список запрещённых оборотов. От этого зависит, будет ли текст звучать как человек или как нейросеть.

## Как устроен поиск

У GigaChat нет встроенного поиска, поэтому бот сам ищет через DuckDuckGo (пакет `ddgs`, ключ не нужен), открывает первые три страницы, берёт начало текста и отдаёт его модели. Это бесплатно, но менее надёжно, чем платный поиск Claude: поисковая выдача может не сработать или быть слабой. В таком случае бот честно напишет в «Что проверить», что факты не подтверждены. **Цены, названия сервисов и вакансии всегда проверяйте глазами перед публикацией.**

## Другие нейросети

В `.env` можно поменять `PROVIDER`:
- `openai`: любой сервис с OpenAI-совместимым API (Groq, Cerebras, OpenRouter и т.д.), нужны `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL`. Доступность из России зависит от сервиса.
- `anthropic`: Claude с встроенным веб-поиском, платно (ключ с console.anthropic.com, `pip install anthropic`).

## Чтобы работал постоянно

Компьютер должен быть включён, пока бот работает. Для постоянной работы поставьте его на недорогой VPS или Raspberry Pi и запустите через `systemd` или `tmux`. Состояние (какие темы уже взяты, черновики) лежит в `state.json`, при перезапуске ничего не потеряется.

## Важно

- Бот отвечает и принимает кнопки только от вашего `OWNER_ID`.
- Платная реклама в канале маркируется по закону отдельно, бот этого не делает.
- Файл `.env` с ключами никому не отправляйте.
